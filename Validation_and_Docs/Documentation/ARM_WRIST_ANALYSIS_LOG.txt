==========================================================================
ORI ARM - WRIST/GRIPPER LOAD ANALYSIS LOG
==========================================================================

Status: CAD/analysis record only. No physical printing or hardware testing.
The current arm implementation is in Source/CAD/Arm/arm.py.

PETG density assumed        : 1.27 g/cm^3  (= 1.27e-3 g/mm^3)
Gravity                    : 9.81 m/s^2
Safety margin (torque)     : 2.0x
HTD-45H nominal torque     : 4.41 N.m (parameterized hardware value)
Estimated continuous value : 2.43 N.m (~55% of nominal; analysis convention, not a manufacturer guarantee)
HTD-45H mass               : 64 g

CURRENT ARCHITECTURE:
  6-DOF arm.
  Grip actuator remains in the forearm/wrist.
  Interchangeable tool contains no servo, motor, battery, or controller.
  Grip transmission in current CAD: spur gear -> coupler gear -> eccentric cam representation -> passive fingers.
  Gear center distance target/parameter: 18 mm.

MASS ACCOUNTING NOTE:
  The current arm generator includes purchased servo envelope geometry inside several
  returned CAD compounds so placement can be visualized. Those compounds must NOT be
  assigned wholly to PETG density. Servo mass is accounted for separately at 64 g each.
  A CAD-volume-derived PETG total is therefore only valid after the embedded servo
  envelope volume is excluded or the source is refactored to return printed-only solids.

PAYLOAD TARGET:
  500 g user target. This remains an engineering target, not a physically verified rating.

CURRENT GEOMETRY:
  shoulder->elbow : 70 mm
  elbow->wrist    : 60 mm
  wrist link      : 28 mm
  grip depth      : 30 mm
  grip target span: 44 mm
  coupler        : Ø34 mm

STATIC TORQUE RELATIONSHIPS:
  Payload torque is computed from payload mass, gravity, and the relevant lever arm.
  Wrist joints have much more torque capacity than the nominal 500 g gravity load.
  Shoulder/elbow are the more demanding arm joints because they carry the longer lever.

VERIFICATION LIMITS:
  Calculation does not prove printed stiffness, servo thermal capability, gear durability,
  grasp reliability, dynamic loads, FDM anisotropy, fatigue life, or power-off backdrive behavior.

HISTORY:
  This log previously contained an erroneous PETG density label (1270 g/cm^3) and mixed
  multiple generations of the gripper concept. This file is now a current-state record;
  legacy architecture belongs in source/reference files rather than being treated as final.
